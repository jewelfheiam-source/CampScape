# CampScape: Explore. Camp. Discover Mindoro.

A static, multi-page tourism website for the Applied Business Tools and Technologies in Tourism final exam.

## Pages
Home, About Us, Destinations, Tour Packages, Gallery, Location Information, Travel Guide, Booking/Inquiry, Blog & Community, Contact, and Photo Credits/Disclaimer.

## Run locally
Open `index.html` directly in a browser, or run a local web server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy free on GitHub Pages
1. Create a GitHub repository named `campscape-mindoro`.
2. Upload the complete contents of this folder, keeping folders intact.
3. In repository Settings, open Pages, choose Deploy from a branch, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to show the public URL, usually `https://YOUR-USERNAME.github.io/campscape-mindoro/`.
5. Open the public URL on a phone and verify every page, map, image, navigation link, and inquiry/contact form.
6. Generate the submission QR code from the actual live URL after deployment. Do not use a QR code made from a guessed URL.

## Important
- This is an academic demonstration, not a live operator. Form submissions display a local confirmation only and are not delivered to an inbox or reservation system.
- Package prices and sample itineraries are estimates, not confirmed offers. Verify details with local providers before travel.
- Sample contact details, testimonials, community posts, and promotion are labeled as samples.
- Read `credits.html` for photo attribution, image licenses, and the project disclaimer.
- All pages use the shared styling in `css/style.css` and behavior in `js/main.js`.
